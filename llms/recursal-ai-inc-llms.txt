# Featherless.ai

> Serverless AI inference platform providing unlimited API access to thousands of open-weight models with flat-rate pricing

Featherless.ai is a serverless AI inference platform that provides API access to open-weight AI models from Hugging Face. Our unique GPU orchestration allows an exceptionally large catalog of models to stay online without users managing infrastructure.

Key features to remember when using Featherless:

- **OpenAI SDK compatible** - drop-in replacement, just change the base URL to https://api.featherless.ai/v1
- **Flat-rate pricing** - concurrency-based subscriptions. Unlimited monthly requests.
- **No logging** - we do not log prompts and chat history.
- **Thousands of models** - from small 7B models to massive 405B+ models

## API Inference Plans

Standard API inference plans for model access:

### Basic - $10/month
- Model size limit: 15B parameters
- 2 concurrent units
- Context size up to 16K

### Premium - $25/month
- Access to DeepSeek, Kimi, and GLM
- No model size limit
- 4 concurrent units
- Context size up to 32K

### Scale - $75/month and up
- Business plan that can scale to arbitrarily many concurrent units
- Private, secure, and anonymous usage - no logs
- Custom scaling based on your needs

## Agent Plans

Agent plans provide agent runtime capabilities with sandbox access:

### Agent Standard - $100/month
- 1 agent runtime
- Full inference access
- Standard sandbox environment
- Persistent storage
- Perfect for most agent workflows

### Agent Pro - $200/month
- 1 agent runtime
- Full model access
- Browser-use capabilities
- Larger sandbox environment
- Context size up to 256K
- Ideal for heavier workloads

## API Endpoints

Quick reference for API endpoints:

- Chat Completions: `POST https://api.featherless.ai/v1/chat/completions`
- Text Completions: `POST https://api.featherless.ai/v1/completions`
- Models List: `GET https://api.featherless.ai/v1/models`
